Mockup: the Visuals tab
Fictional project "Lumen". Scroll the left side: each visual fills the view and the one in the middle becomes current (outline, composer target, notes column all follow). Drag on the current image to mark a region, click for a point pin. Click a faded note to jump to it. Keys for the current visual: ← → pages · R ratio · ↑ ↓ visual · N note · Esc cancel. The strip shows about eight pages with the active one first; Full screen opens the page large. Image content here is generated placeholder art.
